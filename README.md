# FIDO2 evaluation

Zephyr firmware and a Raspberry Pi host for FIDO2 footprint, approval latency,
workflow checks, and periodic-application scheduling measurements.

The [experiment procedure](docs/EXPERIMENTS.md) includes build, flash, calibration,
collection, and CSV commands. Requires Python 3.10+ and a Zephyr checkout with the
FIDO2 Settings and PSA Protected Storage backends.
